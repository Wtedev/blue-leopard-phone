# جوال الفهد الأزرق 🐆

بورتفوليو تفاعلي على شكل جوال ضايع — شاشة قفل، رمز دخول، الأعمال، الملاحظات، الرسائل، الملفات، جهات الاتصال، ولعبة بلوت.

صفحة واحدة: `index.html` (HTML + CSS + JavaScript بدون مكتبات).

## التعديل
- صور الأعمال: مصفوفة `works` في السكربت
- الملاحظات: مصفوفة `notes`
- بيانات التواصل: قسم `#contact`
- رمز الدخول: `CODE` (حالياً 2020)
